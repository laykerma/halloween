# 🎃 Halloween Jumpscare Prank Website 👻

Một trang web Halloween dùng để troll/dọa bạn bè với kịch bản bất ngờ:

## 🎮 Kịch bản trải nghiệm
1. **Mồi nhử (Decoy):** Mini game "Tìm điểm khác biệt giữa 2 bức ảnh lâu đài cổ" với đồ họa kỳ bí, âm thanh ma mị và hướng dẫn nhìn sát vào ô cửa sổ gác mái trong 5 giây.
2. **Khoảnh khắc dọa (Jumpscare):** Tự động toàn màn hình (Fullscreen), nổ tiếng thét kinh hoàng cực đại, hình ảnh ác quỷ rung giật dữ dội và đèn strobe chớp loạn xạ.
3. **Màn hạ nhiệt (Relief Phase):** Sau 2.5 giây, chuyển sang màn hình "HAPPY HALLOWEEN! Bạn đã bị troll haha 🎃👻" với pháo hoa giấy confetti, dơi bay, thống kê nhịp tim vui nhộn và nút sao chép link để troll người khác.

## 🚀 Công nghệ sử dụng
- **HTML5, CSS3, JavaScript thuần** (Single file `index.html`).
- **Tailwind CSS CDN** & Google Fonts (Creepster, Outfit).
- **Web Audio API Engine:** Tự động tổng hợp âm thanh ma mị và tiếng thét chói tai, đảm bảo phát âm thanh 100% không lo bị chặn autoplay hoặc rớt mạng.
- **Canvas Confetti & Particle Animation.**
